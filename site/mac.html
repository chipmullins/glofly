Glofly for Mac

One download for every Mac, Apple Silicon or Intel. Signed and checked by Apple, so it opens like any other app, and it keeps itself up to date.

Download for Mac

Free · macOS 12 or newer · Updates install themselves

Installing

  1. Open the downloaded Glofly .dmg and drag Glofly into Applications.
  2. Open Glofly from Applications. macOS checks that it's from the internet and asks if you're sure. Click Open. You only see this once.
  3. Sign in, or create an account. You're in.

What Glofly asks to use

macOS asks before an app can use these. Each one is only needed for the feature it's for, and you can change them anytime in System Settings → Privacy & Security.

  • Notifications

    Click Allow the first time a message arrives so you see new messages and calls when Glofly is in the background.

  • Microphone and camera

    Asked the first time you join a call or turn on your camera, and for voice messages.

  • Screen sharing

    Turn Glofly on under Screen & System Audio Recording the first time you share, then quit and reopen Glofly.

  • Push to talk

    Optional. Turn Glofly on under Accessibility so your push-to-talk key works while you're in another app.

Updates

Glofly checks for new versions in the background and downloads them for you. When one is ready you'll see Restart to update, or it installs the next time you quit Glofly.

Had the earlier test version?

Download Glofly from this page once and drag it into Applications, choosing Replace. Because this version is signed differently, macOS asks for notifications and the other permissions again, and you'll sign in once more. After that it updates itself.
